# Assent

Low-key. No ceremony.

The body votes. That is a pass. It is not an Act.

Assent is the last act: one clerk button on a Passed file. It writes
`Assented` to the history, stamps who did it, and moves the status to
Enacted. Doing it twice is refused. Doing it before a pass is refused.

The chamber display is not involved. The vote ledger is not rewritten.
