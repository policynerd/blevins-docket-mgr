# FT Sterling

Trial releases, approved for use by the Board.

**They contain 66 glyphs**: `A–Z`, `a–z`, `0–9`, space, comma, period. Nothing
else — no parenthesis, colon, semicolon, hyphen, dash, apostrophe, quote,
slash or ampersand.

The stylesheet applies Sterling to headings only, and the browser falls back
per glyph for anything missing, so nothing renders as a missing-glyph box. The
visible cost, measured on a specimen: the hyphen in `JANET STANTON-BLEVINS`
and the parentheses in `thirty (30) days` come from the fallback face. At
heading size that reads as a slightly foreign punctuation mark. In body copy,
where punctuation is constant, it would read as two typefaces at once — which
is why body text stays in the serif.

Dropping in the licensed release replaces both files and lifts the
restriction; the CSS needs no change.
