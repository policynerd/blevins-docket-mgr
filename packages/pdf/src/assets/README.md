# Brand assets

`board-seal.svg` — official Blevins Holdings Board of Governors seal,
print-safe navy on transparent. Injected into the letterhead at render time.

`board-seal-knockout.svg` — the same artwork as a white knockout for dark
grounds (committee lockups, digital banners). Do not use this on white paper;
it disappears.

`board-lockup.png` / `board-lockup-alpha.png` — raster fallbacks extracted
from a posted meeting notice. Kept so a render still has a mark if the SVG
is missing.

Committee lockups (dark-ground wordmarks) live with the Board brand kit and
are for digital chrome, not the filed instrument. The letterhead uses the
seal, not a committee lockup.
